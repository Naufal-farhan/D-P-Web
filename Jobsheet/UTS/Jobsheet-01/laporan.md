# Laporan Jobsheet 01 — Struktur HTML Sistem Rental Mobil

## Tujuan
Membuat prototipe statis Sistem Manajemen Rental Mobil hanya menggunakan HTML. Pada tahap ini **belum ada CSS dan JavaScript**.

## Halaman yang dibuat
- `index.html`: dashboard, ringkasan jumlah mobil, status kendaraan, dan tabel transaksi terbaru.
- `buku/list.html`: daftar mobil beserta ID, model, nomor polisi, tarif, status, dan aksi contoh.
- `buku/tambah.html`: formulir HTML untuk menambahkan mobil.
- `anggota/list.html`: daftar pelanggan beserta kontak dan kota.
- `anggota/tambah.html`: formulir HTML untuk menambahkan pelanggan.

## Materi yang diterapkan
Kerangka HTML5 (`<!DOCTYPE html>`, `html`, `head`, `body`), elemen semantik (`header`, `aside`, `nav`, `main`, `section`, `article`, `table`, dan `form`), tautan antarhalaman, serta atribut form seperti `label`, `input`, `select`, dan `required`.

## Batasan tahap ini
Konten dan tombol masih berupa prototipe. Tombol Edit/Hapus belum mengubah data, dan form belum menyimpan informasi. Tampilan masih mengikuti gaya bawaan browser karena belum menggunakan CSS.

## Hasil
Jobsheet 01 menjadi fondasi HTML yang akan dihias pada Jobsheet 02, dibuat responsif pada Jobsheet 03, didokumentasikan alurnya pada Jobsheet 04, dan diberi interaksi hamburger menggunakan JavaScript pada Jobsheet 05.
