# Laporan Jobsheet 02 — Styling CSS Sistem Rental Mobil

## Tujuan
Meningkatkan Jobsheet 01 dengan CSS eksternal agar dashboard rental mobil lebih terstruktur, konsisten, dan mudah dibaca. Struktur konten dan contoh data tetap sama dengan Jobsheet 01.

## Perubahan yang dilakukan
- Menambahkan `assets/css/style.css` dan menghubungkannya dari setiap halaman.
- Mengatur warna dasar, font, margin, padding, border, dan box model.
- Membuat sidebar navigasi, topbar, area konten, kartu statistik, tabel, badge status, tombol, dan form.
- Menggunakan Flexbox dan CSS Grid untuk menyusun komponen pada tampilan desktop.
- Menggunakan satu stylesheet bersama agar semua halaman konsisten.

## Konsep CSS yang dipelajari
Selector, deklarasi properti, `box-sizing`, warna, tipografi, `position: fixed`, Flexbox, Grid, border, hover, dan styling komponen form/tabel.

## Batasan tahap ini
Belum ada media query khusus untuk layar kecil. Layout difokuskan pada layar desktop, sehingga pada ponsel sidebar, tabel, dan grid dapat membutuhkan penyesuaian. Penyesuaian tersebut menjadi fokus Jobsheet 03.

## Cara menguji
Buka `index.html`, lalu coba navigasi ke Data Mobil, Tambah Mobil, Data Pelanggan, dan Tambah Pelanggan. Pastikan semua halaman memakai gaya yang seragam.
